# Vitest

Use this skill to write, configure, review, or debug Vitest tests. The agent
identifies the project's Vitest version and test environment, then checks
official guidance on topics such as mocking, coverage, and migrations. See the
[skill instructions](SKILL.md).

## Install with `npx skills`

Run this in the project where you want to use the skill.

```console
npx skills add meza/skills --skill vitest
```

For prerequisites and global installation, see [Install a skill](../../README.md#install-a-skill).

For example, ask your agent to identify which Vitest project and environment
run a test file, then review the relevant configuration.
