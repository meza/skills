# Solid and SolidStart

Use this skill to build, review, or debug SolidJS and SolidStart code, including
reactivity, routing, and rendering. The agent checks the project's framework
versions and rendering mode before applying official guidance. See the
[skill instructions](SKILL.md).

## Install with `npx skills`

Run this in the project where you want to use the skill.

```console
npx skills add meza/skills --skill solidstart
```

For prerequisites and global installation, see [Install a skill](../../README.md#install-a-skill).

For example, ask your agent to review a SolidStart route against the versions of
SolidStart and Solid Router used by your project.
