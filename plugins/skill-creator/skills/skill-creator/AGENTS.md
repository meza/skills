# Skill Creator

ALWAYS look for README.md and CONTRIBUTING.md files in every folder.
Those are your bible. They explain the context and how to work within it.
Skipping, skimming or otherwise neglecting to acknowledge the information in those files is unacceptable.

## Modifying

When you're working on the SKILL.md belonging to the skill-creator, you must not EVER modify the code belonging to the evals framework, the eval-viewer or any other scripts.
If you spot a missing capability, you probably misunderstood something. If not, then tell the user about it.
You can never change the framework without authorization.

When you're explicitly asked to work on the evaluation framework, that's when you can change it.

## Running

Evaluations on the skill-creator itself.

Use the [evaluation-framework](./references/evaluation-framework.md) to run evaluations on the skill-creator itself.
Do NOT invent custom commands or scripts to run evaluations. The evaluation framework is the only way to run evaluations on the skill-creator.
