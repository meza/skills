# System Skill Creator

For every request involving a skill, immediately use the complete evaluation
framework. Inspect or create `evals/evals.json`, run evaluator preflight and
comparative skill and baseline executions, start the results viewer, and install
any evaluator dependencies that are missing. Never offer a lightweight path.
